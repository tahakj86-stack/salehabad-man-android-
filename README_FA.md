# صالح‌آباد من — آماده‌سازی APK برای مایکت

این بسته **سورس پروژه اندروید نیست**؛ شامل APK فعلی شما و گردش‌کار GitHub Actions برای امضای همان APK با کلید انتشار است. این روش فایل فعلی را دوباره کامپایل نمی‌کند.

## مهم
- فایل `salehabad-release-key.jks` و رمزهای آن را در مخزن GitHub آپلود نکنید.
- کلید انتشار را برای نسخه‌های بعدی نگه دارید و پشتیبان امن داشته باشید.
- این بسته، APK را با یک کلید انتشار جدید امضا می‌کند. اگر برنامه قبلاً در فروشگاه با کلید دیگری منتشر شده باشد، برای به‌روزرسانی باید همان کلید قبلی استفاده شود.

## نصب بسته در مخزن
1. محتوای ZIP را در مخزن GitHub قرار دهید و فایل‌ها را در مسیرهای درست حفظ کنید.
2. در مخزن، به **Settings → Secrets and variables → Actions → New repository secret** بروید.
3. چهار Secret را مطابق فایل راهنمای محرمانه‌ای که جداگانه ارائه شده اضافه کنید.
4. به **Actions → Sign Salehabad APK for Release → Run workflow** بروید.
5. پس از موفقیت، artifact با نام `salehabad-man-release-apk` را دانلود کنید.

## محدودیت
امضای مجدد APK تضمین نمی‌کند که مایکت تمام بررسی‌های دیگر را قبول کند. برای ساخت Release واقعی از سورس و اصلاح خطاهای احتمالی، فایل سورس پروژه لازم است.
